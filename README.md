Soy desarrollador full-stack en **Ensenyem**, donde construyo y mantengo un **ERP académico-administrativo** para la gestión de formación profesional. Trabajo con tecnologías web tradicionales y modernas, con un enfoque en sistemas sólidos, mantenibles y que resuelvan problemas reales del sector educativo.
